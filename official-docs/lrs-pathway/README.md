# LRS Access Pathway Pack

Official working documents for **MUCHUO’S CENTRE FOR TRAINING AND DEVELOPMENT LTD** after LRS application **AQEC15U7** was rejected.

## Start here

Open **`LRS-ACCESS-PATHWAY-BRIEF.html`** in a browser (printable one-page brief), then follow:

1. `01-GAP-ANALYSIS-AND-PATHWAY.md` — why rejected and which route to take  
2. `04-DRAFT-EMAIL-BCS-CENTRE-APPROVAL.md` — send first (unlocks eligibility)  
3. `03-DRAFT-EMAIL-LRS-SUPPORT.md` — optional clarification  
4. `02-EVIDENCE-PACK-CHECKLIST.md` + `06-BUSINESS-CASE-OUTLINE-BCS.md` — build the AO pack  
5. `05-LRS-REAPPLICATION-CHECKLIST.md` — only after AO approval is in writing  

## Bottom line

Course materials and UKPRN are necessary but not sufficient.  
LRS needs **Ofqual awarding-body centre approval** for qualifications that go on the **PLR**.  
ISTQB alone does not meet that rule.
