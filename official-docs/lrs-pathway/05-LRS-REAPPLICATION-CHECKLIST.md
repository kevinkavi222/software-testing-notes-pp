# LRS Reapplication Checklist

**Do not start this checklist until AO centre approval for Ofqual-regulated qualifications is complete.**

Previous rejected reference: **AQEC15U7** (for internal tracking only).  
New applications receive a new reference number.

Application service: https://lrs.education.gov.uk/learning-provider-access/application

---

## Before you open the form

- [ ] AO centre approval letter saved (Ofqual-regulated product family named)
- [ ] QAN / qualification list approved for the centre saved
- [ ] Written note that AO uploads (or will upload) achievements to PLR
- [ ] UKPRN 10102202 still active on UKRLP
- [ ] ICO number current
- [ ] Companies House status: Active; signatory is a listed director
- [ ] Super-user identity agreed (name, email, phone)
- [ ] Estimated annual learner registrations prepared
- [ ] One-paragraph business need prepared (see template below)

---

## Business need template (adapt as needed)

> MUCHUO’S CENTRE FOR TRAINING AND DEVELOPMENT LTD is an approved centre with [Awarding Organisation] for the following Ofqual-regulated qualifications: [list / QANs]. We require LRS access to register Unique Learner Numbers for our own learners so that [Awarding Organisation] can validate ULNs and add achievements to each learner’s Personal Learning Record. We do not seek LRS access for any purpose other than registering and supporting our own learners on these regulated programmes.

---

## On the form — watch-outs

- [ ] Legal organisation name matches Companies House / UKRLP exactly
- [ ] UKPRN entered correctly: 10102202
- [ ] ICO number entered correctly
- [ ] Awarding organisation named exactly as on the approval letter
- [ ] Upload AO approval evidence (and funding contract only if applicable)
- [ ] Super-user details are monitored mailbox (not a shared generic inbox that is ignored)
- [ ] Authorised signatory is a Companies House director

---

## After submission

- [ ] Save confirmation / new application reference
- [ ] Diary a follow-up with LRS Support if no decision within their stated service time
- [ ] Do not teach “we are LRS-approved” until written approval arrives
- [ ] Once approved: complete Organisation Agreement, create users with least privilege, issue LRS privacy notice to learners before PLR access

---

## If rejected again

Ask LRS Support for the specific missing criterion in writing, then close the gap (usually: wrong product type accredited, ISTQB-only accreditation, incomplete evidence, or signatory mismatch) before a further application.
